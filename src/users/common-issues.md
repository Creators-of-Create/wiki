# Common Issues
Certain issues occur in certain versions of Create.  
These versions are denoted in the mod filename: `create-minecraftVersion-modVersion.jar`   
For example: `create-1.21.1-6.0.10.jar` would be `6.0.10`

If you find unexpected behaviour that's not listed here, please check [Create Discord](https://r.createmod.net/d) in the `#bugs` channel or [Github issues](https://github.com/Creators-of-Create/Create/issues).

## Known Bugs

<details>
<summary>Create <code>6.0.10</code></summary>

##### Gearbox crashes game when connected to rope pulley with a mechanical drill and Bricks World: [Github Issue](https://github.com/Creators-of-Create/Create/issues/10218)
- Remove Create to rejoin the world. This bug is set to be fixed in version `6.0.11`.

## Frequently Asked Questions

### Can Create gain support for Minecraft version x?
Please refer to this [Important Notice](support-create.md#important-notice-march-2026-until-further-notice) and [Development Status](development-status.md).

### Is Create available on Fabric?
[Yes.](https://modrinth.com/mod/create-fabric)


### When is the next update going to be released?
It'll be ready when it's ready. We appreciate that you are excited for the next release, but you'll have to let us get back to you when the time comes.
Giving out dates puts pressure on development, and will ultimately lower the quality of our content due to deadline induced measures.

### The current version of Create seems to be missing blocks I remember seeing/using previously.
In larger updates we add but also change integral parts of Create.
Usually, [removed features](https://github.com/Creators-of-Create/Create/wiki/Removed-Features) were considered out of scope or have been replaced by something more suitable.

### Can I modify the recipes added by Create?
Yes. All recipes are created within Minecraft's datapack system and can be changed, just like the ones from the base game.  
KubeJS is recommended to customise Create on a larger scale.
